# Security policy

Do not post exploit details, credentials, customer data, or sensitive tenant configuration in a public issue. Report a suspected vulnerability privately to the repository owner using the host repository's private vulnerability reporting feature when available. Include affected versions, reproduction steps using synthetic data, and impact. If private reporting is unavailable, contact the repository owner through an established private channel before public disclosure.

This repository is a reference implementation. Operators are responsible for patching container base images and dependencies, reviewing role assignments and logs, and applying their own network, retention, and compliance policies.
